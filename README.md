倉庫採用分類目錄結構，便於快速瀏覽：

```

├── tech/         # 技術相關資源
├── biz/          # 商業與管理資源
├── design/       # (規劃中) 設計資源
└── README.md     # 本文件

今日產出內容範例：

- `tech/20260617_Linux命令行技巧：提升效率的10個組.md`
